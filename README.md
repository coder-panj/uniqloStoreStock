# uniqloStoreStock
优衣库库存监控
可使用[青龙面板](https://github.com/whyour/qinglong) 定时查询
通知使用wxpush

# 环境变量
1.uniqlo_sku 查询的sku(通过逗号分隔如 111001,111002)
2.productCode spu (只能设置一个, 如111)
3.WXPUHER_APPTOKEN wxpush的SPT
